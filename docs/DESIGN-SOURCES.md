Applied presentation pattern / 采用的展示结构：

1. One-sentence identity and compact status badges / 一句话定位和少量状态徽章。
2. Gallery before implementation detail / 先展示真实成图，再解释实现。
3. Minimal quick start linked to deeper documentation / 最短快速入口连接完整文档。
4. Architecture diagram and explicit component boundaries / 架构图和模块边界。
5. Reproducible examples, validation commands, limitations, and provenance / 可复现例子、验证命令、限制和来源。

No upstream figure, README prose, logo, or source code was copied into BioFigure. / 未复制上游图片、README 文案、Logo 或源代码。
