# BioFigure 顶刊复现语料学习设计

## 目标

将89张“期刊原图＋代码复现图”与349个代码块转成可检索的派生知识，提高BioFigure对图型、布局、配色、标注和R图层语法的判断。不修改GPT权重，不承诺无数据条件下的“一步顶刊质量”。

## 语料与边界

输入为Project_005中79期、89张精选图、286段R、10段Python及53段说明文本。每条派生记录保留期号、源URL、文件SHA-256和置信等级。未验证授权的图和代码仅作本地参考；Skill只写通用规则、API组合与短骨架，不内嵌整图或整段原代码。

## 知识抽取

每期案例卡包含：图型、数据形状、科学问题、图中文字声称的优点、视觉层级、面板结构、图层顺序、配色角色、标注方式、主要R/Python包、可迁移规则、失败风险。图内文字是待审核的来源主张，不自动当作科学事实。配色提取区分类色、连续色、强调色和中性结构色，并检查色盲可辨性。

## 运行链路

1. `route_figure.py`判定图型和科学契约。
2. `retrieve_reproduction.py`按图型、数据、任务检索3–5个案例，输出检索凭证。
3. 模型只读派生案例卡与规则，基于用户数据从空白脚本自然编写R，禁止复制或`source()`原作者代码。
4. `bf_render_png`渲染实际PNG，通过字体、尺寸、文字和哈希凭证。
5. 实际尺寸审图，检查信息密度、边界、标签、图例、色彩与科学语义；不达标则修正。
6. CP0–CP4及Critic全部PASS才可交付。

## 验证

选择生存曲线、带注释热图、环状图、泳道图、富集网络和时间序列等代表图型。每项只给自然语言需求、数据契约和固定随机种子，隐藏原代码。评估R脚本原创性、可运行性、图型语义、视觉指标、实际成图和门禁凭证。基线与升级版使用同一任务比较；只有成功率上升且无科学退化才发布。
