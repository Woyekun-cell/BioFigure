# 多组学案例的统计迁移

本页从作者图与代码提取边界，不替代[统计计划](statistics-workflow.md)。先问意向：整合质量、跨模态关联、方法性能、处理差异或调控验证？同时确认是否同一细胞/个体、多供体/批次、背景集合、单双侧方向。

- 跨平台甲基化：T2T-Y代码用默认Pearson、完整观测和二维分箱；覆盖过滤实际要求至少六列满足5–200，不泛化成所有列。密集数据可用hexbin/二维计数；报告分箱与色标。相关≠一致性；若问一致性，另评估偏差、差值及适用的一致性方法。CpG空间相关不等于独立生物重复。
- 调控区域重叠：SCENIC+ Fig.2d是交集/行集合大小。问富集时另定义共同可检测背景、集合选择过程及多重比较范围；不能直接对比例矩阵套相关检验。
- 三组学标记交集：GLUE源码先各模态Wilcoxon筛标记，再用共同基因背景的三集合检验并做FDR。这是多集合，不是三因素ANOVA；选择阈值、检验族与甲基化反向标记须锁定。组织处理差异另按供体设计建模，不把细胞数当供体n。
- 联合回归：GLUE逐基因拟合RNA~mCH+mCG+ATAC，同样本算R²。迁移为预测任务时按独立供体/批次留出或交叉验证，避免信息泄漏；因素效应问题另审协变量、共线性、交互和误差结构。
- 配对方法指标：scBasset Fig.4b/5b原文为单侧Wilcoxon符号秩；同一细胞/TF作匹配键，审差值分布、方向及重复层级。Fig.5g不同细胞群用秩和，不能混称配对检验。单侧需先有明确科学方向；多比较保留校正说明。
- 等位读数：HPRC ED10d原文用二项检验；新任务先审映射偏差、零假设比例及过度离散，必要时考虑beta-binomial。峰、基因和细胞n分开报告。
- 分类评价：Numbat源码把specificity暂存为precision，但曲线实际x=1-specificity、y=sensitivity，是ROC。按公式审核；PR用TP/(TP+FP)，不能照抄变量名。后验概率、AUC、P、q分别标注。

证据：六篇论文与固定版本代码、行号及哈希均见[案例合同](../library/nature-genomics-multiomics/data/metadata/cases.json)。已完成限定作者数据复算，未跑原始测序全流程；范围见[复现台账](../benchmark/library/nature-genomics-multiomics/data/metadata/reproduction-status.json)。新数据需重新诊断。

实际核对：scBasset配对TF单侧符号秩、渐近近似和连续性校正得到P=0.0338107553；六项细胞群秩和比较也核对原文舍入值，不声称独立供体推断或已做多重校正。Source Data HSC347与图注344单列。SCENIC+原代码复制三个其他方法相关系数，实际结果与该调整分开；不同方法筛选后基因数不等，不把箱线高低当公平同背景性能排序。Numbat零等位logBF给后验0.5，不能补为0。
