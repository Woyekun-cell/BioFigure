# 顶刊美图社四案：复现与稳定调用

来源：86/89/97/98期用户保存的正文、16块R源码；每案只展示一张“论文原图＋顶刊美图社复现图”合成对照。其余81–100期仅有合集预览。论文出处和教程来源见各案`manifest.json`；源码是第三方教程，并非论文作者代码。

## 以后每次调用

先打开来源对照、当前终图及`evidence/visual-review.json`，确认任务和输入适配。固定样例执行：

```bash
python3 benchmark/library/topjournal/scripts/reproduce_saved_cases.py
python3 benchmark/library/topjournal/scripts/verify_simulation.py
```

可加`--issue 97`选案。入口先核对R、实际依赖及字体哈希，渲染后对比锁定输入、代码、几何与PNG像素；偏离即失败，不自动更新基准。新数据沿用已验渲染函数、字号角色、语义色和尺度规则，先运行固定样例，再对新图做终尺寸审核；不能凭旧PASS给新图放行。每次修图重新审核并绑定新哈希。固定样例一致不证明任意数据、跨系统或模型输出质量一致。

## 必须复用的规则

- **86 桑基气泡**：`ggsankeyfier`算节点，气泡复用同一节点中心y；成员关系不是流量。长标签与节点留缝；图例在右。原教程分图导出，组合是独立实现。
- **89 双曲线火山**：两条曲线分支不能跨零连接；NTC选中比例不是BH-FDR。普通基因、NTC、两向hit、MAPT与通路均有图例。repel固定seed、迭代次数；两组图例显式order，防止重跑次序漂移。
- **97 树＋三轨**：树所有枝长须有限且正；渲染x必须等于根到节点累计枝长，禁止缺失枝长触发齐圆退化。主枝0.25 mm、叶点1.8 mm；环按树半径比例：C/W宽各9.5%，共用最大值线性尺度；效果带2.5%。用ggtree坐标生成明确环形矩形，避免fruit逐环归一化。八旁图为模拟独立样本n=12、均值±SE，不做显著性检验。
- **98 分类树四环**：两树各500模拟ASV，分类枝等长1；不可当进化距离。内至外D/Fd/Fz/H，共享12类别图例，标题在上方避免裁切。

字体显式Arial，按各案源码比例配置，不能一律6–7 pt；97分面名、98图例标题加粗。cowplot测量设备用agg，防止默认PDF设备替代字体。PDF连续色条用矢量矩形，核对与PNG色义同向。布局框仅验证画布范围，不冒充实际文字碰撞检测。

原始研究数据仍缺8份。当前工作仅为来源公开的模拟结构复现；数值、像素对原图一致性、盲迁移及压力测试未获验证。来源与复现图、数据、种子、脚本、环境锁和核验证据永久保留。
