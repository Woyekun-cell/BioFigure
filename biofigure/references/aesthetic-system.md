# 发表级审美基线

`GLOBAL AESTHETIC BASELINE`：以下规则对全部图型生效。

机器字段：问题、输入、实验单位、尺度/变换、统计、视觉通道、失败条件、QA、导出；色觉检查属于整图QA。

美观来自清晰层级、精确对齐、受控密度和一致语义，不来自装饰。顺序：科学结论 → 数据契约 → Pattern → 首轮布局合同 → 字体/线宽/留白 → 配色 → 最终尺寸复查。

- canvas、panel、导出背景均为纯白 #FFFFFF；暖白可作发散色中点，不能误作页面背景。
- 默认 Helvetica；Arial 仅在实际设备测得可用且零警告时使用。单图字号层级不超过3级，不靠极小字塞内容。
- 颜色是参数。用户给色板则沿用；否则按数据语义选择。海军蓝—砖红、莫兰迪、马卡龙均只是候选。每个颜色只表达一个变量，不用红绿作唯一编码。
- 线宽、点径、透明度、格子边框按最终物理尺寸确定。重点元素高对比，背景关系降低饱和度；不让所有元素同时高亮。
- 面积编码的气泡/DotPlot使用固定近黑细描边，填色继续承载连续变量；普通散点、UMAP不强制描边。描边粗细按最终点径检查，不能压缩填色面积或制造伪小点。
- 图例在数据区外或由稳定直接标签替代；直接标签后删除重复图例。无大标题、副标题、panel letter、UI卡片、阴影、徽章和解释框。
- 密集层可栅格化；文字、轴、树和关键标注保持清楚。首轮实际PNG出现重叠、裁切、乱码、字体替代或不平衡留白即重画。

Illustrator只允许末端对象级对齐、字距和线端修整；不能改变数值、关系、统计或筛选。
