# SciDraw 56–65 专用包范式

- 时序曲线：均值线与不确定性带分层；阶段边界、干预背景和重复测量误差不可省略。独立观测不得误连成时间序列。
- 地图组成图：底图只承载空间语义；`scatterpie` 扇区表示组成，饼径表示规模。行政区边界使用可追溯地理数据，本批中国一级行政区采用 GADM 4.1；不得用随机多边形冒充省界。图例不得覆盖站点，投影和经纬范围须写入方法合同。
- 对齐组成图：多个堆积面板、点图共享同一行顺序和高度；禁止分别排序后拼接。不同组成变量使用独立色标。
- 花瓣环状柱：每组柱数固定，组间必须留空；外围弧、组名、柱色和数值刻度分别验收。
- 环状柱加饼图：外围柱与中心饼必须来自可核对的层级总量；中心插图不得遮挡柱基线或标签。
- 分面小提琴：分布、箱体和显著性括号分别成层；分面框、标题、量程和比较方向逐面检查。
- 气泡矩阵：x/y 为离散实体，点径映射比例，颜色映射类别或连续量；组间分隔线不得穿过标签。
- 对数点线：先确认 x 是否严格为正，再使用对数轴；多条件曲线应保留离散条件图例，不能用少数连续刻度代替全部实验条件。

模拟复现先匹配原图的数据密度和结构：时序保留局部波动，组成面板使用独立类别与色标，花瓣图保留组间空隙，气泡矩阵保留稀疏对角聚集，显著性图保留括号与标注层。

地图边界、统计显著性与模拟数值必须标明证据来源；缺源数据时只登记方法研究。
