# 语义选图：参考与采纳边界

核对日期：2026-09-19。下列GitHub链接为可变main分支，不代表固定发布版本。

- 本地 `nature-figure/SKILL.md`：沿用静态科学契约、manifest动态路由、按需参考与验图架构；不改变BioFigure既有R优先策略。
- [SciPlot FigureContract](https://github.com/peterbruce716-art/sciplot-figure-skill/blob/main/references/FIGURE_CONTRACT_PROTOCOL.md)：借鉴问题、证据、图型意图的分层及推断溯源，未知结论保持未知；不移植其渲染器和审计包要求。
- [SciPilot选图框架](https://github.com/Haojae/scipilot-figure-skill/blob/main/references/chart_selection.md)：借鉴数据形态、研究意图和规模联合选择，以及同数据不同问题的模式；未复制实现代码。其固定样本量分界、无条件拟合、跨时间合并示例不作为统计规范。
- [Weissgerber等，PLOS Biology，2015](https://doi.org/10.1371/journal.pbio.1002128)：支持小样本展示原始观测、保留配对和分布信息；不将均值误差图当作分布证据。

本地新增情景表是据上述原则与既有领域合同形成的工作规则，不是任何期刊官方规范。profile脚本只描述表格，不自动证明实验单位、因果、显著性或图型最优；语义理解由模型结合实际输入和上下文完成。
