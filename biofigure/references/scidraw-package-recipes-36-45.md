# SciDraw 36–45 专用包范式

本页来源为对应原图与 R 源码的方法抽取；真实任务仍先核对数据字段、实验单位和比较方向。

- 渐变桑基：使用 `networkD3::sankeyNetwork()`；先固定三层节点顺序，再将 source/target 转为从 0 开始的索引。连线宽度只能表示流量；`NodeGroup` 与 `LinkGroup` 分开控制节点和流线颜色。HTML 截图后仍须检查内容框占比。
- 空白行显著性热图：保持一个离散 y 轴，用额外 level 插入间隔；`geom_tile` 表示效应，`geom_text` 表示显著性，`cowplot` 只放侧面组名。禁止用两个独立分面替代空白行结构。
- 多组织火山：总览与 3×3 分面共享阈值和尺度；`ggh4x::facet_wrap2` 管分面条。多细胞火山的 x 为 `-log10(P)`、y 为 log2FC，不得交换。重点基因单独成层。
- 多比较火山：优先 `scRNAtoolVis::jjVolcano()`，保留中央分组色块、左右上下调和组序。包兼容问题只能删除确认为空的图层，不能重写成普通散点后声称使用该包。
- 环形 UMAP：先由 Seurat 坐标和细胞类型生成扇区，再用 `circlize` 画点；条件、时间和细胞类型分别占一条轨道。轨道必须按观测分段，不能整圈填单色。
- 系统发育树：`ggtree` 管树和 clade，`ggtreeExtra::geom_fruit` 管外圈；每增加一种 fill 语义先 `ggnewscale::new_scale_fill()`。连续热图、二元基因环、丰度气泡和门分类不可共用图例。
- OTU 三元图：使用 `ggtern`；三坐标须归一化和为 1。点径表示平均相对丰度，颜色表示富集类别；三角顶点标题、密集度和大点比例逐项核对。
- 蝶状小提琴：左右面板使用同一特征顺序和 x 范围，中间只放共享标签；`patchwork` 固定宽度。阈值线、箱线和小提琴分布分别验收。

源码引用的 Excel、Seurat 对象或树文件缺失时，只能登记为方法研究；不得以相似布局替代数值复现。
