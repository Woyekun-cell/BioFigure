# 泛基因组统计迁移边界

作者代码与Methods同时保留；[逐项差异](../library/pangenome/tomato-superpangenome/data/metadata/source-audit.json)。不同设置不得悄悄替换后仍称原作者复现。

1. 家族单位不同于基因/转录本。固定N时核心=N、特异=1、可变=2..N−1；原文Results与Methods可变定义边界不一致，本案例采用Results并记录差异。Fig2a Source Data核心为21,838家族；正文23,839指core genes，不强行等同。
2. Fig2a完整枚举13材料的k=2..13全部8,178子集，同一材料反复出现。组合不是独立重复，均值与min–max仅描述给定材料的子集差异；不得t检验，也不凭上升曲线认定开放泛基因组。
3. 跨谱系PAV/基因数受组装、注释质量与亲缘混杂。先统一可检测机会；不把几万个家族或邻接窗口当几万个独立材料。未知与真缺失分开。
4. GO源码classic Fisher、BP、nodeSize=5；只导出top100后p.adjust，不能代表全部检验的FDR。新分析先从score(result)取所有合格条目的数值P，统一BH，再截展示条目。背景为可检测且有注释基因；表中“<1e-30”不能直接当精确P。
5. GWAS采用EMMAX亲缘＋PC。原文LD r²0.1/MAF>0.01，代码r²0.2/MAC5；阈值生成步骤依赖外部gec.sum。论文7.58e−7是1/有效标记数，不能跨项目照搬；多性状校正族需按分析意向声明。QQ用全量被测标记，显著峰表不能重建QQ。
6. 原文等位基因比较Student双侧t，REF/ALT以S.galapagense定向。新分析先问描述、调整后关联或验证效应；独立两组考虑Welch，多因素确认交互/协变量；多果实嵌套植株需以植株单位或混合模型处理。基因型小组与群体结构需报告，不能把同一GWAS样本的事后箱线P当独立验证。
