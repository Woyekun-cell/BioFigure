# 基因组、系统树、结构域与共线性

机器字段：问题、输入、实验单位、尺度/变换、统计、视觉通道、失败条件、QA、导出。

所有轨道先声明 assembly、注释版本、坐标制式、染色体命名、方向、树根/分支长度/支持度及关系算法。GFF3 与 BED 转换只做一次并记录日志。

- 树 tip ID 唯一；支持值、缺失值和长度单位与树对象一致。没有长度时画 cladogram，不伪造时间轴。
- 基因结构与蛋白结构域分别使用 nt/aa 尺度；代表转录本、UTR/CDS/exon、重叠域和多转录本规则明确。
- 共线性、orthology、同源比对和局部相似性使用不同 relation type；每条连接有唯一 ID、端点、阈值和置信度。布局连线不能单独证明重排。
- 树叶顺序是跨面板共享 order；结构轨道、标签和连接的 ID 集合差异必须报错，不能静默丢失。
- 染色体分布使用带长度和排序的 assembly 表，明确 bp/Mb、真实长度缩放、窗口/密度分母、未定位 scaffold 和重复位点。各层输入、筛选后和绘制对象计数守恒；负长、越界、未知 contig、重复 display label 或多对多 join 必须报告或失败。
- Circos 只在跨多条染色体的关系结构确实受益时使用。扇区按真实长度，物种间留明确组间隙；连线过滤必须在图例或 manifest 写阈值及输入/显示/隐藏数量。颜色可编码方向或关系类型，但圆形布局和线束方向不能单独证明重排或结构变异。
- 记录树叶中心与结构行中心的对齐偏差、页面/轨道尺寸、字体和线宽；内部唯一 ID 与显示标签分离。

审美：轨道高度、每叶间距、单位、比例尺和最长标签在最终尺寸核对；灰色表示背景关系，强调色只标预先定义的家族/状态。方向箭头表达 strand，不翻转坐标制造结论。
