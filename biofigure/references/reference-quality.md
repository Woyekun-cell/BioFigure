# 参考图质量目标

不是把150种图做成150个固定模板。每次按科学任务、数据形状、实体数、长标签与最终尺寸，从用户示例、SciDraw案例、作者图中找最近的1–3个候选。实际打开图片后才能选为设计依据；只有标题/色号/包名不算视觉学习。图库匹配是候选，旧按页面顺序配对可能错位。

## 编码前写出设计目标

记录参考URL或用户附件、对应panel、已查看证据。提取下面六项，并将采用值写成当前图的mm/pt或明确规则：

1. 主体与层级：最大证据区、辅助层位置；不照搬截图网页外框与讲解文字。
2. 几何与密度：格子/点距、分组间隙、树高、环宽、长标签容纳方式。尺寸由当前数据算，不能强行追求相同画布比例。
3. 色彩：变量到色相/明度的映射、中心值、端点、背景对比；换配色保持语义，不机械复用色号。
4. 文字：一致的字体与字重、普通标签和重点标签的层级；图例名称简短准确。
5. 标记：线宽、点径、描边、透明度、误差线端帽；辅助线视觉重量低于数据。
6. 注释：分类条窄、图例紧凑且独立；需要统计时注释来自实际结果表，禁止堆满所有成对括号。

每项同时记录“参考观察、当前选择、差异理由”。不得只写“Nature风格”“高级简约”。图型选择有争议时先比较两种设计草案再选；普通图不强制多画版本。

## 成图后对照

同等可读尺寸查看参考与产物，比较上述六项。每项写PASS/REVISE及对象级证据；任一明显弱项先修Spec或渲染再开图。空白占比、颜色直方图或相似度只能诊断，不能证明审美相当；不同数据不做逐像素复刻评分。

质量分别报告：科学正确、技术合规、参考设计完成、用户认可。前两项通过不代替后两项。只有用户确认的样例才标human-approved；不声称Skill训练了模型权重或已证明所有图型同级。参考不可访问时用用户已有附件；均不可见则声明视觉对标未验证，仍可完成可审阅图。

## 案例绑定与迁移

网页图像、标题、代码入口必须来自同一案例卡片；禁止按前后标题顺序猜配。`page-card-matched`仅代表来源关联，不代表科学或视觉通过。对照前仍打开实际图片。新网页案例不自动计入旧语料覆盖量。

树＋环形轨道须以tip ID连接，树排序后重排全部轨道；保留枝长含义、圈序和外圈量纲。禁止沿用案例代码截断负系数。云雨图先预留原始点、箱体、半密度和统计槽位，说明密度归一化及检验族。雷达图固定共同尺度和轴顺序，避免用多边形面积解释效应；均值图另附不确定性及逐轴统计。三类图均不得照搬案例字体或模拟数值作为结果。
