# PCA、PCoA、UMAP 与 t-SNE

机器字段：问题、输入、实验单位、尺度/变换、统计、视觉通道、失败条件、QA、导出。

先区分探索结构和假设检验。记录输入矩阵、assay/layer、过滤、缺失处理、中心化/缩放、距离或邻居参数、软件版本和随机种子。

- PCA/PCoA 轴标注方差解释率或距离定义；样本点与 metadata 一一核对。不同模态分别分析，联合降维必须有明确模型。
- UMAP/t-SNE 展示已有 embedding；不要为让组别分开而重跑、调参或修改坐标。相同 embedding 的面板共享 limits 和方向。
- 置信椭圆、凸包和显著性只在样本量与模型适用时使用，并标记其统计含义；不能把聚类视觉分离写成处理效应。
- 离群点不静默删除；若排除，记录原数、规则和原因。
- 记录输入/绘出/抽样点数、点顺序、alpha、raster 策略和抽样种子；同一 embedding 的这些设置跨面板一致。

审美：点大小、透明度、绘制顺序和抽样种子可复现；稀有组不被覆盖；直接标注少量重点群，避免标签云。颜色表达组别，不能同时表达连续表达量。
