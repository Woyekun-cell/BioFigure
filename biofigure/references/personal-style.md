# 用户确认的绘图偏好

这些要求应在第一版成图前实现，不等待用户指出。

- 正式绘图默认R优先：ggplot2、ComplexHeatmap、ggtree、gggenomes、circlize。Python保持兼容；AnnData/Scanpy原生单细胞、Python专用轨道或用户指定时可优先Python。
- 字体用Helvetica或Arial。默认先解析Arial；Helvetica也须实测当前设备，不假定任何字体跨设备必然可用。不得静默回退DejaVu或sans。
- canvas、panel、导出背景使用纯白#FFFFFF。暖白只可作为色阶中点候选。
- 每张图独立生成；默认无panel letter、总标题、副标题、解释框、脚注和重复图例。图注单独保存。
- 配色不是固定模板。可选海军蓝—砖红、莫兰迪、马卡龙或任务特定色板；颜色由语义、中心值、类别数和色觉检查决定。每个颜色只表达一个变量。
- 可读离散热图每格正方、细白/黑边；密集表达/ATAC/ChIP按最终尺寸决定栅格化、分块或总览+细节，不能用不可见边框制造摩尔纹。
- 气泡图使用可填充形状（R常用shape=21）、黑色细描边；点面积映射数量，颜色映射另一明确变量。
- 分类色带只作定位提示，默认宽度≤3 mm；类别名称和颜色含义用独立图例说明，不能让色块抢主体。
- 图例、标签、树和注释有独立bbox；首轮实际PNG不得重叠、裁切、乱码或不平衡。代码可更长，优先换来确定的版式和QA。
- Illustrator只做少量精修；可回写的颜色、位置和间距应回写代码。
- 含生物学重复的组间比较图必须同步完成统计检验：声明分析尺度、总体检验、预设事后比较、多重校正、效应量与精确P/q值；图中标注不得脱离可导出的统计表。若实验设计或配对关系未知，先声明缺口，不得凭图形补造检验。

风格不改变数据、排序、聚类、阈值或统计。
