# 个人绘图偏好

这些要求应在第一版成图前实现，不等待用户指出。

## 选图排序

- 先核候选图层所需字段、连接键和映射。缺字段在卡上注明；仅按授权补模拟字段。
- 数据充分或获准模拟时，优先层次清楚、信息丰富的复合图。如叶名可对齐的环形树＋多圈注释。每圈须有独立含义，按终尺寸可读性取舍。
- 按 [Skill 入口](../SKILL.md#先理解研究再选图)给最多三张不同结构的预览，写适配理由、所需字段，标推荐。等用户选定再读图码和 Benchmark。
- 选图用 `feedback_learning.py retrieve --family <规范figure_family>` 读匹配偏好，定图后按 ID 读模板经验。长期偏好按下节学习。

## 绘图偏好

- 正式绘图默认R优先：ggplot2、ComplexHeatmap、ggtree、gggenomes、circlize。Python保持兼容；AnnData/Scanpy原生单细胞、Python专用轨道或用户指定时可优先Python。
- 字体用Helvetica或Arial。默认先解析Arial；Helvetica也须实测当前设备，不假定任何字体跨设备必然可用。不得静默回退DejaVu或sans。
- canvas、panel、导出背景使用纯白#FFFFFF。暖白只可作为色阶中点候选。
- 每张图独立生成；默认无panel letter、总标题、副标题、解释框和重复图例。严禁画布caption/footer/脚注、样本设计说明、方法或筛选阈值段落；科学内容也移图外图注。正常底部图例/轴保留；必要n、P/q仅作面板内紧凑标注。
- 热图少量数据每格严格正方，最终主体逐slice实测；特别密集才允许显式长方格总览。按最终展示维度判断，不以原始大矩阵豁免小子集，详见[热图硬门](heatmaps.md)。
- 用户不喜欢太暗的数据颜色；新图优先白底、明亮且有区分度的配色，连续量采用完整多色渐变。按[配色系统](palette-system.md)核语义、中心值和色觉；不通过整体降alpha制造浅色，分类色保留标签/形状提示。近色柔和方案不作小点/细线默认；用户及已锁定项目色优先。
- 可读离散热图每格正方、细白/黑边；密集表达/ATAC/ChIP按最终尺寸决定栅格化、分块或总览+细节，不能用不可见边框制造摩尔纹。
- 气泡图使用可填充形状（R常用shape=21）、黑色细描边；点面积映射数量，颜色映射另一明确变量。
- 点线遵守[分层透明度](mark-opacity.md)：样本fill柔和、edge清晰；密集点减少描边，个体线淡、汇总线清晰、区间带轻。连续填色保色标，避免全图统一alpha。
- 分类色带只作定位提示，默认宽度≤3 mm；类别名称和颜色含义用独立图例说明，不能让色块抢主体。
- 图例、标签、树和注释有独立bbox；首轮实际PNG不得重叠、裁切、乱码或不平衡。代码可更长，优先换来确定的版式和QA。
- UMAP 多面板复用同一坐标、点集和范围；模拟坐标应按参考图保留群间接触、桥接和整体紧凑度，不能生成彼此悬空的独立团块。只有原图或分析语义要求局部汇总时才用 hex/bin 热图，不能把所有 cell-level UMAP 统一改成热图。
- 复现以图表结构为主：先锁原图和源码，再独立编码 panel topology、视觉编码、图例与终尺寸。原始数据不可得时可用固定种子结构数据，但必须把结构复现、数值一致和像素一致分开声明。
- Illustrator只做少量精修；可回写的颜色、位置和间距应回写代码。
- 含生物学重复的组间比较图必须同步完成统计检验：声明分析尺度、总体检验、预设事后比较、多重校正、效应量与精确P/q值；图中标注不得脱离可导出的统计表。若实验设计或配对关系未知，先声明缺口，不得凭图形补造检验。

风格不改变数据、排序、聚类、阈值或统计。
