# SciDraw 46–55 专用包范式

- 渐变小提琴：`rasterGrob` 只铺数据面板，`geom_violin` 保留深色轮廓；不同面板可独立量程，标题色带不替代组别编码。
- 分面山脊：用 `ggridges` 保持密度形状；响应正负通过成对透明度表达。分面边界必须连续，不能被浅色主题吞掉。
- 光谱平滑：原始点和 `smooth.spline` 是两层证据；不得只画平滑线。固定坐标范围时先检查越界点。
- 折线加柱形：重复测量趋势、均值误差和原始点分别成层；柱框、误差线及处理组边界颜色按原图检查。
- 对角散点：零线、等值线和旋转差值直方图组成一个统计结构；插图不能遮挡散点或轴标题。
- 环状柱：柱长和连续色阶共同编码数值；同心参考线、分组间隔、外围标签和中心层级均为必要结构。
- 点阵加饼图：点阵按总数排序，饼图汇总同一类别；两者颜色、计数口径和深色轮廓必须一致。
- 样本环图：`circlize` 数值轨与分类轨分开；每轨保留可见边界。侧面箱线图和组成柱必须嵌入同一画布开口，分别与对应数值轨、分类轨的中心和高度对齐；禁止作为独立左栏简单拼接。
- 堆积构成加哑铃：左右面板共享类别顺序；期望区间、期望中位数、观察值和构成比例不得合并成单一散点。
- 双三角相关矩阵：用 `ComplexHeatmap::cell_fun` 画格框和圆；上下三角分别使用色标，圆面积映射相关强度。矩阵网格必须在最终尺寸可辨。

源数据缺失时只能登记为固定种子的方法研究；原图布局接近不能替代数值复现。
