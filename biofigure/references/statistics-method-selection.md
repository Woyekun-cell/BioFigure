# 按设计选择统计方法

先明确目标参数与独立性，再选模型。下表给候选及条件，不按图型、组数或一次正态性检验机械切换。

| 设计/目标 | 候选 | 必查条件 |
|---|---|---|
| 单样本与预设基准 | 单样本t、适合目标的符号/秩检验 | 基准与均值/位置目标明确 |
| 两独立组的均值差 | Welch t优先候选；有方差齐性依据可用Student t | 独立单位、有限值、分布/异常值与样本量 |
| 两组分布/位置比较 | Wilcoxon秩和、合适置换/稳健法 | 不无条件解释为中位数差；形状/离散差异影响解释 |
| 两条件配对 | 配对t、Wilcoxon符号秩；必要时符号法 | 真实ID匹配；配对t诊断差值，符号秩需要合适对称假设 |
| 单因素≥3独立组，均值目标 | 常规ANOVA或Welch ANOVA | 常规模型误差假设；异方差不套常规Tukey |
| 单因素秩/位置目标 | Kruskal–Wallis，适用时Dunn等事后法 | 组间独立；分布差异不自动等于中位数差 |
| ≥2设计因素，连续结局 | 因子线性模型/ANOVA含计划交互项 | 见多因素规范；不把所有组合当单因素解释交互 |
| 同单位多次或嵌套观测 | 重复测量模型、混合模型；完整单因素区组可考虑Friedman | 相关结构、缺失、随机效应与诊断 |
| 连续预测量/协变量 | 回归、ANCOVA、必要交互与非线性 | 目标、线性/残差、混杂和斜率假设 |
| 二元、计数、比例、等级 | 二项/计数/有序GLM或相应混合模型 | 分母/暴露量、过度离散、零膨胀或分离等 |
| 列联表/配对二元 | χ²或Fisher；配对可McNemar | 期望频数、独立性，非比例均值ANOVA |
| 生存、多变量、组学 | 生存模型、MANOVA/PERMANOVA或领域流程 | 删失、比例风险、距离/离散、置换限制与FDR |

均值ANOVA常规两两比较可Tukey；对照目标可Dunnett；Welch常见候选Games–Howell；非参数事后须匹配总体方法。预设对比不一概以总体P<0.05为唯一开关，遵守既定检验策略；探索事后按预先说明的流程处理。

这些方法检验不同假设，不为得到显著结果互换。效应、置信区间及独立n与P一起报告；不显著不证明等效。[实现与来源](statistics-sources.md)。
