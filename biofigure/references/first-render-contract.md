# 首轮布局合同

写代码前固定以下槽位，代码必须直接实现，不留给“第二版再调”。

| 槽位 | 必填内容 |
|---|---|
| canvas | 宽高mm、`#FFFFFF`、单图/组图、最终缩放 |
| data bbox | 主体位置、宽高、坐标比例、分片/gap |
| annotation bbox | 树、样本条、模块条、统计层的独立空间 |
| legend bbox | 数据区外；标题、刻度、行列数、语义字典 |
| labels | Helvetica/Arial、字号、最长文本、旋转/换行、选标规则 |
| font file | 用 systemfonts/grid 或后端等价方法解析真实文件；记录路径并验证所有层继承 |
| text metrics | 在目标设备、字号和最终mm下测每段文字宽高，不用字符数估算 |
| preflight | 由已测 bbox 计算坐标；首轮渲染前检查 canvas 内含与对象相交 |
| export | R/Python设备、PNG dpi、矢量/栅格层、重开检查 |

首轮正向配方：先定最终物理尺寸 → 测最长文字 → 为注释与图例留固定空间 → 再计算数据区 → 渲染同维度数据 → 打开 PNG 检查。自动布局只可微调，不能替代上述分配。

首轮坐标由测量与约束推导；发现设备差异允许重测和修订，不能用反复猜坐标代替设计。极坐标、树、轨道、嵌套图和多图例也必须先计算内外半径、文字切向/径向 bbox 与可用空隙。首轮出现明显碰撞视为 Design Spec 缺陷：先改槽位、文字策略或坐标生成规则，再整体重画，不能只补丁式缩字。

硬失败：非授权的文字遮挡、图例侵入数据区或互斥槽位相交；对象超出画布；missing glyph、字体替代或设备警告；应为白底却出现暖灰背景；同一颜色表达两个变量；直接标签后仍保留重复图例；标题、panel letter 或解释框进入未要求的单图。

字体解析成功只证明候选文件存在。PNG须核对实际字形、字重和跨层一致性；SVG/PDF另查字体族、替代和嵌入/可编辑状态。未完成成图字体核对不得 PASS。

密集层先决定是否栅格化。若逐格边框在最终尺寸小于可辨线宽或产生摩尔纹，使用“全量密集总览 + 稀疏标注/局部细节”，并记录取舍；不得假装每格仍可读。

ComplexHeatmap首轮还须测试内部临时PDF测量设备；系统字体文件存在并不保证anno_text可测量。列文字实测宽度加间距超过列pitch时旋转或扩格；不得等用户发现标签挤成一行。
