# 情景驱动选图

下表是条件式候选，不是列名匹配器或封闭白名单。

| 情景与目的 | 优先表达 | 数据条件与解释边界 |
|---|---|---|
| 独立组，比较连续响应 | 原始点与明确的中心/区间；分布可用ECDF或箱线 | n按独立单位；小样本不靠平滑外形断言分布；无通用n阈值保证密度可靠 |
| 同一对象前后变化 | 配对点线、个体差值 | 验证ID和条件键唯一及缺失；无配对键不按行号连线 |
| 时间/剂量动态 | 实际间距的点线、分面轨迹 | 区分重复测量与各时间独立取样；独立样本不画个体连线 |
| 同一数据，问终点差异 | 预设终点的组间/配对比较 | 不因观察到最大差异才选终点而隐去选择过程 |
| 同一数据，问个体异质性 | 个体轨迹或变化分布 | 不跨时间混池充当独立重复 |
| 只有均值与SD/SEM/CI | 点与对应误差或明确要求的柱图 | 不反造原始点、箱线或小提琴；误差定义未知则暂停误差层 |
| 两变量关系 | 散点；过密时分箱 | 拟合与相关须匹配尺度和设计；相关不证明因果 |
| 表达矩阵，看样本结构 | 合适变换后的PCA、样本相关图 | 需样本映射与矩阵层；不能把分离等同显著差异 |
| 表达矩阵，看特征模式 | 注释热图 | 声明筛选与标准化；行Z分数不代表跨基因绝对量 |
| 已有差异分析结果 | 效应排序、火山或MA | 核对效应方向、p/q来源；MA需平均丰度；原始矩阵不能直接冒充差异表 |
| 组成或转移 | 比例点图/堆叠；真实流量可流图 | 核对分母、互斥与总和；不同时间的比例不等于对象转移 |
| 单细胞/视野嵌套 | 单位内分布与样本级汇总 | 细胞/视野数量不充当供者/动物n；保留层级 |
| 生存结局 | 生存曲线与风险表 | 需时间、事件编码和删失信息；普通时间列不够 |
| 预测评估 | ROC/PR、校准或误差图按问题选 | 需真实标签、预测值和独立评估来源；不能以训练表现冒充外部验证 |

指定图型科学可行时尊重用户；不合适先解释失真点。多因素优先考虑分面和主次问题，拆分依据实际标签/图例密度，不照搬固定类别数禁令。结构图、机制图和空间/基因组图继续走现有专项合同。
