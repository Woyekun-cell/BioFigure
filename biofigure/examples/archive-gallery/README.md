# 图库脚本存档 / Gallery script archive

这里保存本地成图批次的自编生成脚本快照，供核对方法与后续复现使用；不包含第三方来源图片或抓取代码。现有PNG按原文件哈希同步，本轮没有重跑全部绘图。

脚本保留原有相对路径和依赖；公开数据脚本的个人绝对路径已改为 `BIOFIGURE_FIXTURE_ROOT` 环境变量；部分需要本地绘图CSV、Design Spec、字体、公开数据或地图边界。该目录不是已经通过全环境复现验证的独立运行包。原始数据、绘图CSV、环境记录与复现配置仍保留在图库清单标示的原项目中。

[分类图库](../../../docs/GALLERY.md) · [逐图清单](../../../docs/gallery/catalog.json)

Snapshots of locally authored generators are retained for method inspection. Paths and dependencies may require adjustment; some scripts need local CSVs, design specs, fonts, public datasets or map boundaries. Existing PNGs were copied without rerendering. This archive does not assert portable execution or full benchmark acceptance.
