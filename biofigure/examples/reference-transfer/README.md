# 三个来源知情绘图示例

三个案例从参考图的表达方式出发，用模拟数据重新编码。森林图用模拟估计量计算 t 区间和 BH 校正；突变热图不对分类格插值；时序 SEM 跨同一主体内的模拟 trial 计算。

从本目录运行：

```sh
Rscript scripts/draw.R
```

依赖ggplot2、patchwork、ragg、dplyr、scales、systemfonts及Arial字体。生成PNG、CSV和sessionInfo。

来源：https://mp.weixin.qq.com/s/2B95P3is3_NWGJmcY9prsQ 、 https://mp.weixin.qq.com/s/tUMyotJO99TeRRJFYbzG6g 、 https://mp.weixin.qq.com/s/mAOgsMJJJnHVHHMteS5O_A

执行记录：采用先查看参考再编码的方式（非盲测），完整 CP 门禁尚未全部完成。
