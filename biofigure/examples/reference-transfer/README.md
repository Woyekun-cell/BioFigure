# 三个来源知情绘图示例

使用模拟数据，先查看参考后重新编码；不是盲测，也未完成全部CP门禁。森林图用模拟估计量计算t区间和BH校正；突变热图不对分类格插值；时序SEM跨同一主体内的模拟trial计算。

从本目录运行：

```sh
Rscript scripts/draw.R
```

依赖ggplot2、patchwork、ragg、dplyr、scales、systemfonts及Arial字体。生成PNG、CSV和sessionInfo。
