# Supplemental Reference Transfer Critic

仅在 Figure Design Spec 选择 SciDraw 等补充案例时启用。先核对 case/visual ID、状态和对应关系；`needs_review`、未配图或许可不清必须显式保留，禁止提升为已验证证据。

逐项对照：迁移的是层级、几何、排序、留白、注释带、图例槽位和配色语义；不得迁移未知数据处理、统计结论、字体默认值、装饰或源代码。科学契约、官方指南、数据语义和当前 Pattern 优先。

若成图仍出现宽分类带、图内拥挤图例、彩虹色、过密标签/显著性括号、装饰性环图、黑底、双轴、网络毛球或碎片化拼版，记 major。若补充参考改变统计单位、尺度、阈值、变量顺序含义或结论，记 hard。

PASS 必须记录采用项、拒绝项、最终尺寸视觉证据及源状态；“风格相似”“更好看”不是证据。
