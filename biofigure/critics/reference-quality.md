# 参考图设计审查

读取Spec的design_target及当前渲染图，不使用案例数量、代码长度或自拟总分替代审查。

逐项比较hierarchy、geometry、palette、typography、marks、annotation；每项记录参考观察、当前对象和差异理由。目标是当前数据下同样清晰精致的构图，不复制无关结构。

PASS：六项均有具体视觉证据且无待修缺陷；REVISE：任一项明显弱于选定参考或只有形容词；NOT_ASSESSED：没有看到参考或产物。未收到用户确认不得写human-approved或保证顶刊接收。

例：热图类别条2mm、方格2.5mm、图例离主体4mm是可执行设计；“使用漂亮配色和合理布局”不是。数字只作当前任务选择，不是所有图的固定比例。

证据写入critic_reviews.reference-quality.dimensions，每个维度含status与evidence；不能用一段总评代替。
