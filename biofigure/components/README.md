# Visual components

组件是可组合的视觉语法，不是完整模板。每个组件声明语义、输入、硬约束、兼容 Pattern 和 renderer。

- `annotation.yaml`：样本、模块、条件条带。
- `labels.yaml`：直接标签、选定标签、避让和稀有群体绘制顺序。
- `legends.yaml`：外置、共享、直接标注和重复图例检查。
- `statistical-layers.yaml`：阈值、区间、显著性和模型说明。
- `genomic-tracks.yaml`：坐标、方向、关系带、比例尺。
- `marks.yaml`：气泡面积/填色双编码与黑色细描边。

组件不能改变原始值、统计、排序、关系数量或实验单位。
