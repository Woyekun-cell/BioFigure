# 统一图形立场

出版基线见 `source-index://nature-research-figure-guide-2026`；期刊具体要求优先于本默认值。

先选图的科学角色，再选图形。主图建立一个清楚的视觉英雄区；辅助层只解释主证据。定量图、结构/轨道图、图像板、树、机制图和非对称多面板各用适合的视觉语法，不强制转成柱图或热图。

默认单图独立生成，最后再拼版。画布纯白；只有原始显微/组织图像本身可保留黑底，外围版面仍遵循交付约定。数据墨水优先，去掉无意义标题、装饰框、重复图例和自动面板编号。注释带窄而克制，图例避开数据区并预留真实包围盒空间。

优先 R；单细胞等生态需要时可锁定 Python。颜色由语义和可访问性决定，连续量用有序/发散多阶色，分类色保持可辨且不过饱和。最终结论只以实际打开的目标尺寸 PNG/SVG/PDF/TIFF 为准，代码成功不等于成图通过。

首轮代码必须先做布局预检：按最终尺寸测文字尺寸，预留数据、注释和图例槽位并完成碰撞预检，禁止凭经验猜绝对坐标。字体可找到不等于实际字形合规；须锁定字体文件、要求所有绘图层继承，并在成图中核对。实际看图用于发现设备差异，不能代替首轮设计。
