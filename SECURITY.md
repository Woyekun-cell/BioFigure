# 安全与敏感数据 / Security and sensitive data

请勿在公开 Issue、Discussion、Pull Request、日志或示例数据中提交访问令牌、患者标识、未公开研究数据和受限数据库内容。发现凭据泄露时应立即在原服务撤销或轮换凭据，再清理公开记录。<br>
Never submit access tokens, patient identifiers, unpublished research data, or restricted database content in public issues, discussions, pull requests, logs, or examples. If a credential is exposed, revoke or rotate it at the issuing service before cleaning the public record.

安全漏洞请通过仓库的 [Security advisory](https://github.com/Woyekun-cell/BioFigure/security/advisories/new) 私下报告，说明受影响版本、复现步骤、影响和建议修复。普通绘图缺陷请使用 Issue 模板。<br>
Report security vulnerabilities privately through a [Security advisory](https://github.com/Woyekun-cell/BioFigure/security/advisories/new), including the affected version, reproduction steps, impact, and suggested remediation. Use the Issue forms for ordinary figure defects.

BioFigure 不处理患者级数据托管，也不替代机构伦理、数据管理和计算环境安全要求。<br>
BioFigure does not provide patient-data hosting and does not replace institutional ethics, data-management, or computing-security requirements.
